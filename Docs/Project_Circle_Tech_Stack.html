Project Circle is a 2D story-driven action platformer about discrimination. The player is a mute circle cast out by a world that ranks shapes by their number of corners. It is built in Unity with C#, for Windows PC, playable with keyboard and mouse or a gamepad.

4. GAME ARCHITECTURE

The code is split into small modules, each with one job. Modules talk through C# events, so the UI and story react to gameplay without being tied to it.

PlayerMovement, quickstep dash, jumps, the cape and its abilities (blade, pogo, parry, double jump, Mend)
CombatHealth, damage, hit effects and invulnerability
EnemiesTriangle enemies with AI by rank: scalene, isosceles, equilateral; sentries, chargers, swarms
BossesBoss brain with phases and attack moves (the Base Warden)
World & ProgressRoom transitions, camera, gates, abilities and story flags carried between areas
Story & UIOpening sequence, Mirrors (checkpoints and the circle's thoughts), dialogue, HUD
How a frame flows: Input System → Player (movement, abilities) → Physics → Combat (hits, health) → events → UI and story react. Enemies and bosses run their own AI against the same physics and combat systems.
